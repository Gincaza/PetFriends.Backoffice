# PetFriends.Backoffice

Este é um aplicativo de console em C# para gerenciar informações de animais de estimação no sistema PetFriends.

## Funcionalidades

- Listar todos os animais cadastrados
- Adicionar um novo animal
- Garantir que as idades e descrições físicas estejam completas
- Garantir que apelidos e descrições de personalidade estejam completas
- Editar a idade de um animal
- Editar a descrição de personalidade de um animal
- Exibir todos os gatos com uma característica especificada
- Exibir todos os cachorros com uma característica especificada
